# Project Context

These files are the canonical durable context for humans and coding agents.

## Fast orientation

Read first:

1. `MISSION.md` — why the project exists.
2. `CONSTITUTION.md` — non-negotiable engineering rules.
3. `TECH_STACK.md` — selected technologies and intentional non-selections.
4. `ROADMAP.md` — where the project is going.
5. `CURRENT_STATE.md` — what is actually implemented now.

Then read the active feature spec.

## Deeper context

- `PRODUCT.md` — product/domain scope and behavior.
- `ARCHITECTURE.md` — detailed system design.
- `WORKFLOW.md` — SDD and multi-agent development process.
- `CONVENTIONS.md` — coding/data/naming conventions.
- `DECISIONS.md` — durable architecture decisions.
- `COMMANDS.md` — stable project command interface.

`AGENTS.md` at repository root tells Codex, Claude Code, Kiro and other coding agents how to consume this context.

The repository should remain sufficient for handoff without relying on private chat history.
