# Mission

## Purpose

Build a production-oriented, multilingual RAG assistant for Way2Australia that provides grounded, cited answers from approved public knowledge while also serving as a portfolio project for learning and demonstrating real-world RAG engineering.

## Primary objectives

### 1. Useful product
Provide reliable answers for Way2Australia and NAATI CCL-related questions using approved sources and clear citations.

### 2. Engineering learning
Use the project to deeply understand and experiment with:
- ingestion;
- chunking;
- embeddings;
- dense and sparse retrieval;
- hybrid retrieval;
- reranking;
- query transformation;
- context construction;
- grounded generation;
- citations;
- evaluation;
- security;
- observability;
- reliability;
- deployment;
- cost and latency tradeoffs.

### 3. Portfolio evidence
Demonstrate engineering judgment through:
- measurable experiments;
- architecture decisions;
- quality/latency/cost comparisons;
- regression testing;
- tracing;
- security controls;
- graceful degradation;
- reproducible deployments.

The project should be understandable and usable by a recruiter or interviewer without requiring a long explanation.

## Current mission boundary

Phase 1 focuses on a public/guest multilingual RAG assistant.

Phase 2 focuses on Knowledge Operations:
- S3-backed document storage;
- admin document management;
- Knowledge Release workflow;
- evaluation governance;
- auditability;
- basic analytics.

Authenticated/private retrieval, broad agent orchestration, and unrelated platform features are future work.
